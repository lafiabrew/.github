# lafiabrew

Open-source console homebrew games, save editors, wireless SD/log servers, and hardware diagnostic utilities organized by target system.

## Nintendo 3DS (`3ds_*`)

| Project | Short Title | Code & UniqueId | Description |
|---|---|---|---|
| [**3ds_hub**](https://github.com/lafiabrew/3ds_hub) | **3DS Hub** | Host (`:8765`) | Universal FBI QR & network installer hub (`serve_3ds.py`) + PC companion tools (`sd_scanner.py`, `pkhex_web.py`, `romhack_tool.py`). |
| [**3ds_pieceduel**](https://github.com/lafiabrew/3ds_pieceduel) | **PieceDuel** | `CTR-P-PD3D` (`0x0D3E0`) | Stereoscopic 3D 4-in-a-Row strategy game (AI, Daily Puzzles, 3DS Local Wireless `nwm::UDS`, LAN P2P, and Web Cross-Play). |
| [**3ds_pokedash**](https://github.com/lafiabrew/3ds_pokedash) | **PokeDash** | `CTR-P-PKDS` (`0x0D3E1`) | Permissive PKHaX Gen 3–7 & ROM-hack surgical Pokémon save editor + Type/Nature/Shiny/EV calculator. |
| [**3ds_sysdash**](https://github.com/lafiabrew/3ds_sysdash) | **SysDash** | `CTR-P-SYSD` (`0x0D3E2`) | CFW hardware/battery/IP inspector, 1-button Luma3DS LayeredFS ROM-hack mod toggler, and crash log snapshotter. |
| [**3ds_drop**](https://github.com/lafiabrew/3ds_drop) | **3DS Drop** | `CTR-P-DROP` (`0x0D3E3`) | Wireless LAN HTTP & Web UI SD card scanner, crash log harvester, and atomic save/ROM file drop server (`:8766`). |
| [**3ds_wigle**](https://github.com/lafiabrew/3ds_wigle) | **WiGLE 3DS** | `CTR-P-WIGL` (`0x0D3E4`) | `WigleWifi-1.4` CSV wardriver, 2.4 GHz Ch 1–13 spectrum analyzer, and 3DS Local Wireless (`nwm::UDS`) beacon radar. |
| [**3ds_rngtool**](https://github.com/lafiabrew/3ds_rngtool) | **PokeRNG** | `CTR-P-PRNG` (`0x0D3E5`) | Pokémon RNG shiny frame finder, TSV/G7TID calculator, and Luma3DS Rosalina `cheats.txt` generator. |
| [**3ds_netpass**](https://github.com/lafiabrew/3ds_netpass) | **NetPass** | `CTR-P-SPAS` (`0x0D3E6`) | 3DS Play Coin maxer (300 coins with `.bak` backup), pedometer step tracker, and StreetPass `CECD` box vault. |
| [**3ds_padtest**](https://github.com/lafiabrew/3ds_padtest) | **PadTest** | `CTR-P-PADT` (`0x0D3E7`) | Circle Pad drift & deadzone analyzer, button tester, dead-pixel screen cycler, and hardware JSON report exporter. |
